# Competency and Retrieval Maps

Use these as defaults, then customize to the target role.

## Sales / GTM

| Question signal | Competency | Story pattern to retrieve |
|---|---|---|
| AE, seller, deal, close | AE partnership | Customer blocker -> discovery -> technical proof -> opportunity progresses |
| Technical blocker | Deal de-risking | Uncertainty -> validation -> stakeholder confidence -> next decision |
| Discovery changed recommendation | Discovery / judgment | Requested solution -> underlying need -> new recommendation |
| Executive audience | Executive communication | Technical complexity -> business narrative -> decision artifact |
| Customer objection | Objection handling | Objection -> diagnose -> valid blocker or misunderstanding -> action |
| Expansion / cross-sell | Commercial discovery | Existing problem -> adjacent need -> better-fit product |
| Seller disagreement | Trusted advisor | Sales pressure -> technical/customer risk -> constructive pushback |
| Repeatable playbook | Scaling Sales | One-off solution -> documented pattern -> broader field reuse |

## Product / EPD

| Question signal | Competency | Story pattern to retrieve |
|---|---|---|
| Noisy signals | Product discovery | Many anecdotes -> classify -> reproduce -> systemic pattern |
| Customer feedback changed recommendation | Adaptability / judgment | Initial hypothesis -> disconfirming evidence -> new recommendation |
| Requested feature | Problem framing | Feature ask -> underlying outcome -> actual problem |
| Product disagreement | Product influence | Customer evidence -> internal trade-off -> advocate -> decision |
| Not-now / Product says no | Stakeholder management | Advocate -> understand constraint -> communicate -> preserve trust |
| Prioritization | Strategic thinking | Many issues -> impact/frequency/workaround -> ordered response |
| High agency | Bias for action | Ownership gap -> smallest useful intervention -> learn / unblock |
| Did it get better? | Measurement | Baseline -> intervention -> observable change |

## Technical / Architecture

| Question signal | Competency | Story pattern to retrieve |
|---|---|---|
| Scale | Architecture trade-offs | Current load -> bottleneck -> target state -> operational implications |
| Reliability | Failure-mode thinking | Dependency fails -> graceful degradation -> recovery / observability |
| Migration | Pragmatism | Current system -> incremental path -> risk containment |
| Security | Trust boundaries | Sensitive data -> boundary -> auth / secrets / logging |
| Performance | Systems thinking | Latency source -> measurement -> architecture choice |
