# Recommended Workflows

## Workflow A — Build the interview foundation

Input:
- job description;
- recruiter brief;
- interview stages;
- resume;
- performance reviews;
- existing story library.

Output:
1. Role summary
2. Interview-stage map
3. Competency map
4. Existing-story coverage
5. Story portfolio gaps
6. 3-5 highest-priority stories per interview lane

## Workflow B — Turn a raw recollection into a story

Prompt the candidate to dump the story naturally.

Then:
1. Extract facts.
2. Separate facts from inference.
3. Identify the decision arc.
4. Identify candidate ownership.
5. Identify stakeholder roles.
6. Identify trade-off.
7. Identify missing verification.
8. Build structured JSON.
9. Suggest strongest question mappings.
10. Create STAAARL card.

## Workflow C — Build retrieval readiness

For each high-value story create:
- one-line memory hook;
- STAAARL card;
- 2-4 default questions;
- 2-3 dangerous questions where the story is only a backup;
- 3 likely follow-ups;
- missing facts to verify.

Then create a compact role-specific retrieval map.

## Workflow D — Mock interview

1. Select interview lens.
2. Ask one question.
3. Wait for answer.
4. Give concise strengths/gaps/reframe.
5. Identify story fit.
6. Ask a probing follow-up if the answer lacks depth.
7. Only move on once the missing signal is demonstrated or explicitly noted.

## Workflow E — Review a transcript

For every Q&A:
1. Judge question realism and competency.
2. Assess answer content.
3. Assess story fit.
4. Search existing story library for a better match.
5. Explain better retrieval.
6. Provide a skeleton, not a memorized script.
7. Add one likely follow-up.

End with:
- recurring failure patterns;
- 3-5 retrieval-ready stories;
- role-specific retrieval map;
- three questions to practice next.
